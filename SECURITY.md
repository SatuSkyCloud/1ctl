# Security Policy

## Supported versions

Security fixes are provided for the latest published `1ctl` release. Upgrade
before reporting an issue that only affects an older release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue or discussion containing credentials,
personal data, exploit code, or details that would make an unpatched issue
easier to abuse.

Include the affected version, operating system, reproduction steps, impact,
and any suggested remediation. We aim to acknowledge a report within three
business days and will coordinate disclosure after a fix is available.

If private vulnerability reporting is unavailable, contact the repository
owners privately through the SatuSky support channel and reference `1ctl`.

## Secrets

If a report includes a potentially exposed credential, revoke or rotate it
before sending diagnostic material. Redact tokens, kubeconfigs, private keys,
and authorization headers from logs and screenshots.
